thermite#

Built for the Autoresearch Era

ThermiteOS redefines operating system design by utilizing self-correcting agents to discover, patch, and optimize kernel modules and userland programs.

Redox Microkernel Core

Built directly upon the Redox kernel, featuring a microkernel architecture where drivers, filesystems, and network stacks run safely in user space. Inherently immune to classic memory corruption bugs.

Continuous Auto-Synthesis

Integrates autoresearch loops directly into the package manager. The OS identifies dependencies, queries developer knowledge graphs, resolves build errors, and adapts code natively for the Redox ABI.

Rust-First Architecture

From the bootloader to the terminal shell, every component leverages Rust's strict safety guarantees. ThermiteOS eliminates undefined behavior while retaining full bare-metal performance.

System Design

Redox Microkernel meets Autoresearch Agents

Traditional operating systems suffer from monolithic bloat and manual maintenance bottlenecks. ThermiteOS addresses this by decoupling critical components and wrapping them in automated agentic feedback loops.

01

Microkernel Separation

Systems drivers and components are isolated processes, limiting the blast radius of any individual failure.

02

Autoresearch Daemon (ard)

A background system daemon that monitors userland build failures, reads system logs, and queries local models to write source-level repairs.

03

Self-Improving Userland

Packages are continuously rebuilt and verified under test suites, creating a self-healing OS distribution that evolves without manual packager intervention.
